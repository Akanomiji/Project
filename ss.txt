🎨 1. ฝั่งหน้าบ้าน (Frontend - React Vite)
ฝั่งนี้คือส่วนที่แสดงผลดีไซน์และหน้าจอเกจวัดความปลอดภัย 99% ที่เราทำกันครับ

สิ่งที่เครื่องคนอื่นต้องติดตั้ง:

Node.js (เวอร์ชัน LTS): จำเป็นต้องติดตั้งลงเครื่อง เพื่อใช้รันเซิร์ฟเวอร์จำลองของหน้าบ้าน

ขั้นตอนการรันบนเครื่องคนอื่น:

เปิด Terminal / VS Code ในโฟลเดอร์หน้าบ้าน

พิมพ์ npm install (เพื่อโหลดพวกไอคอน lucide-react และ Tailwind CSS)

พิมพ์ npm run dev เพื่อเปิดหน้าเว็บ

⚙️ 2. ฝั่งหลังบ้าน (Backend API & AI Model)
ฝั่งนี้คือตัวคำนวณและส่งค่าคะแนนอย่าง "score": 99 มาให้หน้าบ้าน สิ่งที่ต้องติดตั้งจะขึ้นอยู่กับว่าหลังบ้านของคุณเขียนด้วยภาษาอะไรครับ:

🐍 กรณีที่ 1: หลังบ้านใช้ Python (เช่น Flask / FastAPI)
สิ่งที่เครื่องคนอื่นต้องติดตั้ง:

Python (เวอร์ชัน 3.9 ขึ้นไป): ต้องติดตั้งลงเครื่องก่อน

ขั้นตอนการรันบนเครื่องคนอื่น:

เปิด Terminal ในโฟลเดอร์หลังบ้าน

พิมพ์ pip install -r requirements.txt (คำสั่งนี้จะดาวน์โหลดไลบรารี AI หรือแพ็กเกจเซิร์ฟเวอร์ทั้งหมดที่หลังบ้านต้องใช้มาลงเครื่องเขาโดยอัตโนมัติ)

พิมพ์คำสั่งรันระบบ (เช่น python app.py หรือ uvicorn main:app --reload)
